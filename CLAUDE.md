# Project Instructions

**@marianmeres/sqlkit**: a thin SQL toolkit for PostgreSQL and SQLite. `sql` fragments,
one driver contract over node:sqlite, node-postgres, PGlite and Durable Objects, typed
errors, transactions, statement builders, row decoders, retry, health and migrations.

See [AGENTS.md](./AGENTS.md) for the project documentation and agent instructions. The gate
is `pnpm run ci`.
